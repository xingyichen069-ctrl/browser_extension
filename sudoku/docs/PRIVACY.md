# 隐私与数据说明

适用版本：数独手记 1.0.0。无账户、无服务器、无遥测、无云端上传。

## 实际读取

- Sudoku.com 当前棋盘的公开 `gameData` 白名单字段：题号、棋盘类型、难度；`window.mode` 表示普通/每日/活动模式。
- `#game` 的存在、`#win-screen` 的明确胜利状态及 `#timer` 文字。
- 可信棋盘鼠标/键盘交互的发生；不记录每个输入值或键盘历史。
- 仅普通经典/杀手模式，在需要辨认重新开始时只读 `main_game` / `main_game_killer` 精确键，并要求其题号、模式、难度与当前页一致。只使用重开标志与计时值，不保存题解/完整棋盘，不枚举其他站点存储。

## 保存内容与位置

扩展自己的 IndexedDB 保存事件 ID、站点固定名称、类型、难度、模式、UTC 完成时刻（自动记录）、完成时当地日期与时区、可识别的用时、来源、题目标识和用户备注。手动补记不伪造精确时刻。

页面自己的 `sessionStorage` 中另有扩展命名的临时键，保存本标签的尝试标识、有界待保存队列和隔离故障材料，以便刷新/重试。它不是长期统计库，同源网页能访问 Web Storage；里面不放密码、账号、Cookie、完整浏览历史或其他网页数据。

记录与回收站合计上限五万条。删除记录进入七天回收站；过期时或永久删除后只留下最多三十天、没有题目/日期/备注内容的随机事件 ID，用于阻止迟到的重复消息。到期清理在下次访问/写入数据库时执行，不用后台定时器。

诊断隔离最多保留二十项有界条目；未知版本、过大的或损坏的原始会话内容保持原样，不用当前版本覆盖。诊断导出会包含这些待恢复信息，请只在确需协助修复时自行分享。

## 权限及通信

Manifest 的站点权限只覆盖 Sudoku.com 及 www 子域。顶层内容脚本桥接只读页面元数据到扩展隔离环境，后台按来源和字段格式验证消息。它用于个人日志，不是防作弊或成绩认证系统。

没有网络上传代码、远程字体/脚本、第三方分析 SDK，也不读其他网站。该扩展不阻止 Sudoku.com 自身的网络请求或其自有 Cookie；这些仍按网站和浏览器设置运行。

## 导出、迁移与删除

JSON/CSV 通过本地下载保存，由用户决定位置。备份是普通明文文件，包含个人游玩日期和备注；不会自动上传或加密。卸载扩展会删除扩展数据库，换电脑、浏览器配置或安装目录时需先导出再导入。

普通备份不包含回收站；需要保留的记录应先恢复。InPrivate 不启用此扩展，以免将隐私窗口的游戏混入日常历史。
