# 数独手记

给 Sudoku.com 留一本本地成绩簿。平时照常玩，成功完成后记录日期、类型、难度和用时；想看最近玩了多少局、哪种难度花时间，可以打开统计页筛选。

它不解题，也不会把安装前的成绩补回来。

## 开始用

1. 解压仓库，在 Edge 打开 `edge://extensions`，开启「开发人员模式」。
2. 点击「加载解压缩的扩展」，选择本工具的 `extension` 文件夹，里面应能看到 `manifest.json`。
3. 刷新已经打开的 [Sudoku.com](https://sudoku.com/zh/)，打开工具栏的「数独手记」，确认显示已识别的游戏类型和难度。
4. 继续玩这一局，获胜界面出现后再关闭网页。记录不要求统计页一直开着。

安装目录要保留。扩展菜单里可以把图标固定到工具栏，之后点击图标看今日和累计摘要，进入完整统计页看明细、九十天日历和难度分布。

## 常见用法

- **只想看本周练了多少：** 在统计页选日期范围，再按类型或难度筛选。表格每页最多五十条。
- **漏记了一局：** 手动补记日期和已知信息。只知道日期时不补造具体时间，用时不知道也可以留空。
- **记错了：** 删除后进入七天回收站，可以撤销或恢复。
- **换电脑或整理数据：** 导出 JSON 留作备份；CSV 适合在表格软件里看，不用于完整恢复。

自动计数需要先观察这一局的操作，再看到明确的胜利界面。隐藏的祝贺文字、旧胜利页面和重复消息不会直接计数。插件不判断有没有使用提示。日期按实际观察到完成时的本地日期记录，包括补做过去的每日挑战。

## 备份和更新

在统计页「导出 JSON 备份」，确认文件下载成功。换电脑或重装后导入，记录会校验后合并；重复导入同一备份不会让次数翻倍。回收站不在普通备份内，需要的记录先恢复。

卸载会删除这份扩展的本地数据库，先备份。更新则保留原安装目录、替换文件，在 `edge://extensions` 点「重新加载」，再刷新游戏网页。更换目录可能改变扩展身份，不能靠搬目录代替备份。

## 范围和问题

主要覆盖经典、杀手数独；每日挑战会单独记录模式。活动页面依赖网站提供的信息，网站改版或无法识别时以工具栏状态为准，必要时手动补记。其他数独网站和 InPrivate 窗口不在支持范围内。

| 现象 | 先做什么 |
| --- | --- |
| 提示未连接 | 确认扩展已启用、允许在 sudoku.com 运行；刷新实际棋盘页面 |
| 有待保存记录 | 保留该标签页，点重试；仍失败就导出待恢复数据 |
| 导入被拒绝 | 用完整 JSON 原件，最多 64 MiB、五万条；同 ID 不同内容会整批拒绝，现有记录保留 |
| 达到五万条 | 先备份，再整理记录和回收站；不会自动删最旧成绩 |
| 游戏结束却没记录 | 暂停、禁用、过早关页面或网站识别变化都可能漏记，可手动补记 |

故障导出的「待恢复数据」不是普通备份，不能直接混进成绩簿。

权限只覆盖 Sudoku.com；没有分析服务或远程脚本，记录只存在本地。详细说明见 [隐私](docs/PRIVACY.md)、[备份字段](docs/BACKUP_FORMAT.md) 和 [维护与验证](docs/MAINTENANCE.md)。
