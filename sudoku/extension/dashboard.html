使用说明

第一次安装与连接
  1. 在 Edge 打开 edge://extensions，开启“开发人员模式”。
  2. 点击“加载解压缩的扩展”，选择包含 manifest.json 的 extension 文件夹；保留这个文件夹。
  3. 刷新 sudoku.com 网页，在工具栏打开“数独手记”，确认当前页面状态。

不需要一直打开这张统计页。历史成绩不会自动回溯，可以用“补记一局”添加。

自动记录条件

自动统计从插件连接后开始，只记录适配器捕获到的新成功。完成后请等胜利动画和成功界面显示，再关闭网页；如果工具栏仍提示未保存，请保留标签页并先导出待恢复数据。

网站改版、权限变化或插件禁用可能导致漏记；可以检查连接并手动补记。完成日期按当时的本地日期保存，跨午夜的游戏计入完成那一天。

更新、换电脑与重新安装

先导出 JSON 并确认文件已保存。更新时保留原安装目录，在 Edge 扩展管理页点击“重载”，再刷新数独网页。

换电脑、换浏览器配置或移动扩展文件夹，请按迁移处理：在新环境安装后导入 JSON。Edge 账号同步不会代替这份备份。

隐私、容量、暂停与卸载

记录只保存在当前浏览器配置的本机数据库中，不上传，也不在 InPrivate（隐私浏览）窗口启用。有效记录和回收站合计最多 50,000 条。

备份是普通明文文件，请自行妥善保存。“暂停自动记录”会保留历史，暂停期间不补抓。卸载扩展会清除本地记录，请先导出 JSON，确认下载完成后再到 Edge 扩展管理页移除。
