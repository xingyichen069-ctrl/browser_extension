# 验证范围

`npm test` 检查域名边界、路径边界、类型匹配、优先级、导入校验等纯规则。`npm run test:browser` 在独立 Edge 中检查规则管理、文件交付、多选、回退、暂停与清理；测试网页和文件均为合成数据。

浏览器测试预先授予测试域名权限，并用真实 OPFS 句柄和内存文件替代系统选择窗口。因此不能据此声称已验证原生 Windows 窗口的默认目录、用户首次授权弹窗或登录状态下的真实课程网站。

实际使用前可以做一次小检查：绑定一个没有敏感内容的目录，选一份用于测试的文件，确认系统窗口位置、网页收到的文件名和网站自身的上传结果。取消窗口后也应能继续用原方式上传。

每次浏览器测试将当前结果写入本机 `qa/browser-report.json`，其中保留执行时间、测试项目、限制及源码散列。这些运行资料不随公共仓库分发。

公开整理检查（2026-10-12）：规则 13 项、浏览器 20 项通过。使用当前公开副本执行；这些结果仍受上述隔离环境与原生选择窗口的验证范围限制。
