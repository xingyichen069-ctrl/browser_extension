# 维护上传文件夹规则

| 文件 | 职责 |
| --- | --- |
| `core.js` | 域名、路径、文件类型与规则优先级 |
| `options.*`、`db.js` | 规则编辑、按需网站授权、目录句柄保存 |
| `background.js` | 注册网站脚本，管理上传会话和选择窗口 |
| `content.js`、`main-hook.js` | 拦截支持的文件控件，保留原方式回退 |
| `picker.*`、`bridge.*` | 选择文件并通过一次性通道交付给原网页 |

在工具目录运行 `npm ci`、`npm test`、`npm run test:browser`。需要 Node.js 20+ 和本机 Edge；`python tools/package.py` 需要 Python 3.12+，生成的 ZIP 包含 `extension/`、使用说明和通用规则示例。

浏览器测试是隔离环境，用 OPFS 句柄代替系统目录弹窗，不会提交真实作业。更改权限或上传事件流程时，重点检查拒绝授权、取消选文件、关闭弹窗、文件类型不符和回到原上传方式，具体范围见 [验证记录](VERIFICATION.md)。

公开版 1.0.1 去除了个人目录预设，保留需要使用者亲自绑定的 Canvas 示例。规则逻辑与本地版本一致。勿将目录授权、真实规则导出、浏览器配置或测试生成的 `qa/` 提交到仓库。
