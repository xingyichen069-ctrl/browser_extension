# 上传文件夹规则

给不同网站记住常用的上传目录。例如课程网站默认选作业 PDF，图片网站默认选素材目录，同一个网站也可以按页面路径或文件类型分开设置。

点击网站的上传入口后，扩展先打开一个小窗口。你再点「选择文件并交给网页」，从已绑定的文件夹选文件。它不会直接改写网站原来的系统文件窗口，也不会自动扫描文件夹或替你提交表单。

## 第一次设置

1. 解压仓库，在 Edge 打开 `edge://extensions`，开启「开发人员模式」。
2. 点「加载解压缩的扩展」，选本工具的 `extension` 文件夹。
3. 点击工具栏的扩展图标，进入规则管理页。
4. 填网站域名、页面路径和文件类型；点击「选择并绑定文件夹」，亲自选一次常用目录。
5. 点击「授权网站并保存规则」，确认访问权限，再刷新目标网页。
6. 点击网页上传入口，在扩展窗口里选文件。文件回到网页后，检查结果，再按网站原有步骤提交。

管理页有交大 Canvas 的 PDF 示例：`oc.sjtu.edu.cn`、路径 `/`、类型 `.pdf`。示例没有替你获得目录或网站授权，需要自己绑定。其他学校或网站可以直接改域名。

## 怎样安排规则

| 场景 | 设置例子 |
| --- | --- |
| 整个课程网站共用作业目录 | 域名填课程网站，路径 `/`，类型 `.pdf` |
| 只在课程页面生效 | 路径 `/courses`，会包括 `/courses/12345`，不会包括 `/courses-extra` |
| 同站图片和文档用不同目录 | 各建一条图片、文档规则，分别绑定文件夹 |
| 几个网站共用目录 | 在「默认文件夹」里复用已有绑定 |
| 网页没有标文件类型 | 用「所有文件」，或在弹窗中选择规则；高级设置可填上传控件的 CSS 选择器 |

更具体的域名、路径和控件规则优先。类型根据上传框声明的 `accept` 判断，扩展在你选文件前并不知道你会选什么。`example.com` 包含子域名时不会匹配 `example.com.evil.test`。

## 暂停、迁移与更新

临时不想用它，点网页右下角「使用原上传方式」，或在管理页暂停某条规则／全部规则。

导出 JSON 保存规则。导入是追加，导入的新规则默认暂停，需要重新绑定文件夹和授权网站。导出不含文件内容、完整本地路径或目录句柄。更新保留原安装目录，替换源码后到扩展管理页重新加载，再刷新网页。

文件夹被移动或授权失效时重新绑定。删除规则不会删电脑里的文件；已授予的网站访问权限可在 Edge 扩展详情中撤销。

## 什么时候用原上传方式

常见单选、多选、标签触发和连接在页面上的文件控件可以接管。下面这些场景可能无法接管：整文件夹上传、摄像头拍摄控件、网站直接调用系统文件 API、关闭的 Shadow DOM、特殊上传组件或受限制的 iframe。

跨域 iframe 需要按它自己的域名设置并授权。浏览器内部页、扩展商店不允许普通扩展接管。网站若拒绝程序触发的文件事件，也请切回原方式。

扩展每次把绑定目录作为系统窗口的 `startIn` 交给浏览器，最终显示的起始位置仍由 Edge 和操作系统决定。有的网站选好文件就立即上传；本工具只负责交付选中的文件，不替你确认提交结果。

## 权限与数据

`storage` 存规则，IndexedDB 存目录句柄；`scripting` 只在你明确授权的网站装入适配脚本。虽然扩展允许申请任意 HTTP(S) 网站权限，安装时并不会自动获得所有网站访问权。

没有独立服务器或统计服务，不保存选中文件的副本。文件通过一次性通道交给原网页。更多实现与测试边界见 [维护说明](docs/MAINTENANCE.md) 和 [验证记录](docs/VERIFICATION.md)。
